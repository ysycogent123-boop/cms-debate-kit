# CMS Debate Kit

Create a reusable classroom debate kit from the excerpt and any supplied debate rules or forms. Keep every substantive claim within the evidence available in the excerpt.

## Non-negotiable rules

- Treat the excerpt, debate rules, and supplied forms as protected originals. Never edit, rename, move, overwrite, or delete them.
- Do not introduce facts, background knowledge, author biography, plot details, statistics, or arguments that are absent from the excerpt as debate evidence.
- When a requested claim or detail is unsupported, write exactly `발췌문에서 확인 불가` instead of guessing or filling the gap.
- Quote the excerpt verbatim. Preserve wording, spelling, punctuation, and meaningful omissions; never silently paraphrase text presented as a quotation.
- Attach the source paragraph number to every quotation. If the excerpt has no paragraph numbers, create a separate working paragraph map without altering the original, and state that the numbers are working identifiers.
- Store all newly created deliverables in the current project's `결과물` folder. Create that folder only when authorized. Never save generated deliverables beside or over the protected originals.
- Mark uncertain facts or figures as `확인 필요`. Do not let such material function as excerpt evidence.
- Before creating or changing files, inspect the current state, present the proposed filenames and absolute save paths, and obtain explicit user approval. Change only the approved files.

## Workflow

### 1. Inspect and map the source

Identify the excerpt, debate rules, templates, requested audience, and output format. Read source files without modifying them. Build a working paragraph map that preserves the original order and makes each paragraph uniquely citable.

If the source text is incomplete, illegible, or ambiguous, distinguish what can be read from what requires confirmation. Use `발췌문에서 확인 불가` for content absent from the excerpt and `확인 필요` for uncertain transcription or metadata.

### 2. Develop the proposition

Draft a clear, debatable proposition that both sides can address using the excerpt alone. Check that affirmative and negative positions each have a plausible path to textual support. Narrow or revise a proposition that requires outside knowledge.

Record:

- the proposition;
- the central conflict or decision exposed by the excerpt;
- supporting paragraph numbers for each side;
- any requested issue that is `발췌문에서 확인 불가`.

### 3. Create evidence cards

For each evidence card, include:

- side or position;
- claim stated as an inference or argument, not as a fabricated fact;
- verbatim quotation;
- paragraph number;
- a short explanation of how the quotation supports the claim;
- limitations or counter-readings visible in the excerpt.

Reject a card when its quotation does not support its claim, its paragraph number is missing or wrong, or the explanation depends on outside information. Do not disguise paraphrases as quotations.

### 4. Create the worksheet and rubric

Build the activity sheet around the approved proposition and validated evidence cards. Provide space for claim, quotation with paragraph number, reasoning, anticipated counterargument, response, and reflection when appropriate to the requested format.

Make the rubric observable and excerpt-bound. Evaluate criteria such as:

- fidelity and relevance of textual evidence;
- accurate paragraph-number citation;
- reasoning from quotation to claim;
- engagement with counterarguments;
- compliance with the supplied debate rules;
- clear distinction between excerpt evidence and unsupported material.

Do not award credit for external factual knowledge unless the user explicitly establishes a separate research phase. Even then, keep it labeled separately from excerpt evidence.

### 5. Validate citations and consistency

Perform a final source-to-output audit:

1. Match every quotation character-for-character against the excerpt.
2. Confirm every paragraph number points to the quoted text.
3. Confirm each evidence-card claim is reasonably supported by its quotation.
4. Search the proposition, cards, worksheet, rubric, and teacher guidance for unsupported factual assertions.
5. Replace absent support with `발췌문에서 확인 불가`; mark uncertain facts or figures `확인 필요`.
6. Confirm no protected original was modified and every deliverable is under `결과물`.

Report each citation as pass, correction needed, or `발췌문에서 확인 불가`. Do not report a clean validation when any quotation or paragraph number remains unchecked.

## Completion report

After finishing, summarize the number of created or changed files and their final absolute paths. Provide a table with:

| File | Change | Review item |
|---|---|---|
| Absolute path | Created or updated | What the user should verify |

Also state whether quotation fidelity, paragraph numbering, excerpt-only evidence, original preservation, and `결과물` placement passed validation.
